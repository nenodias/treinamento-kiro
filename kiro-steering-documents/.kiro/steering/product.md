# Visão Geral do Produto

Este repositório é um **material de treinamento** para ensinar desenvolvedores a utilizarem Steering Documents no Kiro IDE.

Ele contém:
- Um conjunto de módulos progressivos (em português) cobrindo conceitos, configuração, modos de inclusão, referências, casos de uso reais e boas práticas de steering documents.
- Um projeto de exemplo funcional (`projeto-exemplo/`) — uma API REST simples de gerenciamento de tarefas que demonstra steering documents em ação.

A API de exemplo gerencia "tarefas" com operações CRUD e serve como sandbox para experimentar diferentes configurações de steering.

## Idioma

Toda documentação, comentários no código, nomes de variáveis e endpoints da API são escritos em **Português Brasileiro**.
