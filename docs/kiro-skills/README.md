# 🧩 Treinamento: Agent Skills no Kiro

## Sobre este treinamento

Material de **20 minutos** para capacitar desenvolvedores a criarem, importarem e utilizarem **Agent Skills** no Kiro IDE — pacotes portáveis de instruções que estendem o conhecimento do agente com workflows reutilizáveis.

## Estrutura do Treinamento

| Módulo | Tema | Tempo |
|--------|------|-------|
| [Módulo 01](modulos/01-conceito-e-criacao.md) | O que são Skills e como criar | ~8 min |
| [Módulo 02](modulos/02-importar-comandos-e-uso.md) | Importar, comandos e uso no dia a dia | ~7 min |
| [Módulo 03](modulos/03-demo-pratica.md) | Demonstração prática | ~5 min |

## Projeto de Exemplo

A pasta `projeto-exemplo/` contém skills prontas para testar: code review, documentação de API e commit messages.

## Pré-requisitos

- Kiro IDE instalado
- Familiaridade básica com Markdown
