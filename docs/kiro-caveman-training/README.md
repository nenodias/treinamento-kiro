# 🦴 Treinamento: CAVEMAN Mode no Kiro IDE e Kiro CLI

## Objetivo

Demonstrar como o **CAVEMAN mode** reduz drasticamente o consumo de tokens (~75%) mantendo total precisão técnica. Ideal para sessões longas, projetos complexos e times que querem maximizar o contexto disponível.

---

## O que é CAVEMAN?

CAVEMAN é um skill do Kiro que comprime a comunicação agent ↔ usuário:

- **Remove**: artigos (a/an/the/o/a/os/as), fillers, pleasantries, hedging
- **Mantém**: termos técnicos exatos, código, nomes de API, comandos, mensagens de erro
- **Resultado**: ~75% menos tokens por resposta, sem perda de substância
