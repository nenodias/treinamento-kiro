# Projeto: API de Tarefas

## Sobre
API REST para gerenciamento de tarefas pessoais.
Stack: Node.js 20, Express 4, armazenamento em memória (demo).

## Arquitetura
- Camadas: routes → services → models
- Routes: recebem request, chamam service, retornam response padronizada
- Services: validação e lógica de negócio
- Models: acesso a dados e estrutura

## Comandos
- Instalar: `npm install`
- Dev: `npm run dev`
- Testes: `npm test`
- Lint: `npm run lint`

## Idioma
- Código: variáveis e funções em português (camelCase)
- Comentários: português
- Commits: português
