# Product Summary

This is a **Kiro Workshop** repository — a hands-on training project demonstrating Kiro IDE and Kiro CLI features.

## What it contains

- **Workshop modules** (`modulos/`): Markdown guides covering each Kiro feature (Vibe & Spec, Steering, Hooks, Subagents, Powers/MCP, CLI)
- **Demo project** (`projeto-demo/`): A Node.js task management API used as the live demo during workshops

## Demo API — Task Management

The demo API provides:
- Create tasks with title, description, and priority (baixa/media/alta)
- List all tasks
- Mark tasks as completed
- Subtask support (linked to a parent task)

Domain language is **Portuguese (pt-BR)** — variable names, error messages, and documentation are all in Portuguese.

## Audience

Backend developers learning to use Kiro IDE in their workflow. The project is intentionally simple to keep focus on tooling, not business complexity.
