# Padrões do Time Backend

Este Power encapsula os padrões e convenções do time backend para projetos Node.js.

## O que inclui

- **Steering**: Guia de convenções de código aplicado automaticamente
- **Convenções**: Nomenclatura, estrutura de projeto, tratamento de erros

## Como usar

Ao ativar este Power, o Kiro seguirá automaticamente as convenções do time ao gerar ou revisar código:

1. Nomenclatura em português para domínio
2. Arquitetura em camadas (handlers → services → utils)
3. Tratamento de erros padronizado
4. Respostas HTTP consistentes
